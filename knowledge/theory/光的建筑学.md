# 光的建筑学

## 核心概念
光不仅是照明的工具，更是塑造空间体验的核心材料。建筑中的光具有双重属性：物理性（亮度、方向、色温）与精神性（神圣、静谧、时间感）。光通过界定边界、揭示材质、制造阴影，使空间从“容器”转变为“事件”。光的进入方式（缝隙、天窗、反射）决定了空间的氛围与意义。建筑师的职责不是“设计光”，而是设计“光的缺席与在场”——通过控制暗，来定义亮。

## 设计启示
| 启示 | 设计应用 |
|------|----------|
| 光缝制造神圣感 | 在实墙中开一道窄缝，让光线以“刺入”方式进入，形成强烈的方向性与仪式感 |
| 彩色光孔营造精神氛围 | 在厚墙中嵌入彩色玻璃或滤光片，将日光转化为有色光，赋予空间冥想气质 |
| 间接光柔化空间边界 | 利用反射面（如浅色天花、地面）将直射光转为漫射光，使空间边界模糊、时间感减缓 |
| 阴影是光的另一半 | 设计时先画“暗区”，再决定光从何处切入——暗的深度决定了光的强度 |
| 光随时间变化 | 引入可移动遮阳或季节性光孔，让空间在一天/一年中呈现不同表情 |

## 可用于
- 宗教建筑（教堂、寺庙、冥想空间）
- 纪念馆与殡葬建筑（营造静谧与追思）
- 美术馆与展览空间（控制光对展品的干扰与强调）
- 住宅的走廊、楼梯间（用光引导路径与情绪）

## 案例关联
- **光之教堂（安藤忠雄）** ：在清水混凝土实墙中开出一道十字形光缝，光线以唯一来源进入，使整个黑暗空间被一道“光之十字”激活。此案例完美体现“光作为精神性材料”——光不再是照亮，而是成为空间的神圣符号，暗部成为信徒凝视的虚空。
- **朗香教堂（勒·柯布西耶）** ：厚墙上的彩色光孔（红、蓝、黄）将日光分解为色块，投射在弯曲的墙面上，形成如星云般的光斑。此案例展示“光作为氛围制造器”——彩色光改变了空间尺度感，使混凝土墙体变得轻盈、神秘，光成为进入空间的“神谕”。
