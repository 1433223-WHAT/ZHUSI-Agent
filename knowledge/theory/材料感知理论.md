# 材料感知理论

## 核心概念
材料感知理论认为，建筑体验不仅由空间形态决定，更由材料的物理属性（质感、温度、硬度、反光度）直接触发。人对材料的感知是触觉优先的——眼睛看到的光泽与手摸到的温度共同构成“真实感”。材料具有时间性：木材会老化、石材会风化，这种变化让建筑成为“记录时间的容器”。材料的“距离感”也很关键：粗糙表面拉近身体，光滑表面制造疏离。最终，材料不是表面的装饰，而是空间意义的直接生产者。

## 设计启示
| 启示 | 应用方式 |
|------|----------|
| 触觉优先于视觉 | 在扶手、墙面、地面等身体常接触的部位，选用真实材料（石材、木材），避免廉价贴面 |
| 温度感制造情绪 | 用混凝土/石材营造清凉沉静，用木材/砖营造温暖亲近，形成空间的情绪对比 |
| 时间性作为设计参数 | 选择会自然老化的材料（铜绿、木纹加深），让建筑随时间“生长”出层次 |
| 质感对比强化感知 | 在同一空间中并置粗糙与光滑（如粗石墙+抛光地面），通过反差唤醒触觉敏感度 |
| 材料边界定义空间 | 用材料变化替代墙体分隔，地面材质切换即可暗示功能区的转换 |

## 可用于
- 温泉、浴室等触觉主导的疗愈空间
- 美术馆、纪念馆等需要时间沉思的文化建筑
- 住宅中的核心起居空间（强调温暖与归属感）
- 景观建筑中的路径与停留节点（材质引导脚步节奏）

## 案例关联
**瓦尔斯温泉（卒姆托）**：石材被切割成薄片层层叠砌，墙面保留粗糙的凿痕，与水的湿润、皮肤的触感形成三重感知叠加。石材的冰凉与温泉的热度对比，让“温度”成为空间体验的核心叙事。**巴塞罗那德国馆（密斯）**：大理石、缟玛瑙、玻璃、钢的边界处理极为精确，材料之间不融合、不遮挡，而是通过抛光的镜面感与石材的天然纹理，让“材料边界”本身成为空间划分的逻辑——视线穿透，触觉却止步于光滑表面，制造出若即若离的感知距离。
